# 📖 MeTruyenChu - Mobile

A free mobile application for reading online stories, developed using React Native and Expo.

## 🚀 How to Run the Application

### System Requirements
- Node.js (> version 18)
- npm
- Expo CLI
- Expo Go

### How to Run
Run the command below and scan the QR Code with Expo Go on your mobile device
  ```bash
  npx expo start
  ```
